# StyleFlow 设计摘要

> 本文是早期 11 份设计文档（`docs/design/`）与 `docs/项目规划` 的浓缩版，原文件已删除（可用 git 历史找回）。
> 代码是最终事实来源，本文只记录**仍然有效的约定**。

## 定位

AI 驱动的服装设计—生产协同平台。目标用户：设计师、版师、财务、ERP 同步账号（角色见下）。

## 架构

```
浏览器 ──► Next.js（唯一对外端口 3000，同源代理 /api、/media、/static）
              └─► Django + Django Ninja（/api/v1）
                     ├─ 数据库：SQLite（默认）/ PostgreSQL
                     ├─ 文件：本地磁盘 data/media（可切 S3/MinIO）
                     └─ 任务：进程内线程池（默认）/ Celery + Redis
```

- 后端：Django 6 + Django Ninja（Pydantic v2 序列化），模块化 app，`common/` 存放公共能力。
- 前端：Next.js 16 App Router + Ant Design + zustand；API 走同源相对路径 `/api/v1`。
- 部署形态以 `start.py` 一键本地运行为主，详见 [运行与部署](运行与部署.md)。

## 业务模块（`backend/apps/`）

| 模块 | 职责 | 关键模型 |
|---|---|---|
| `accounts` | 用户、JWT 认证、角色权限、AI Key 加密存储 | `User`、`Profile`(role)、`UserAISetting` |
| `design` | AI 设计工坊：文生图/图生图、设计稿与版本 | `Design`、`DesignVersion` |
| `tryon` | 虚拟试衣任务（当前为模拟流程，可接 IDM-VTON） | `TryOnTask` |
| `techpack` | 工艺单：AI 生成 + 尺码表/工序/面料 | `TechPack` |
| `workflow` | 可视化工作流：定义、实例、认领、推进/驳回 | `WorkflowDefinition`、`WorkflowInstance` |
| `costing` | 核工价：按工序模板核算 | `CostingResult`、`ProcessTemplate` |
| `wages` | 计件工资报表 | `WageRecord` |
| `erp` | ERP 直连同步（款式/工序标准），未配置时接口返回友好提示 | `ErpStyle`、`ErpProcess` |
| `media` | 媒体库：上传、分类、回收站、批量操作 | `UserMedia` |
| `planning` | 商品企划（占位，无模型） | — |

公共约定：`common.models.TimestampMixin` 提供 `created_at/updated_at`；`common/storage.py` 统一文件读写与 URL 生成；`common/taskqueue.py` 统一任务提交与状态查询；`common/crypto.py` 用 Fernet 双层加密 API Key。

## API 约定

- 前缀 `/api/v1`，接口文档 `/api/v1/docs`（Ninja 自带 Swagger）。
- 认证：`Authorization: Bearer <access_token>`，access 30 分钟、refresh 7 天，`POST /auth/refresh` 续期。
- 前端调用统一同源相对路径；后端返回的文件地址统一为 `/media/...`（可用 `BACKEND_BASE_URL` 改成绝对地址，仅前后端分离时需要）。
- 列表接口分页参数 `page`/`page_size`；错误以 4xx/5xx + JSON 消息返回，不存在资源用 404。

## AI 服务层

`common/aiservice/factory.py` 统一构建服务实例，按「用户配置 → 系统默认」回退：

- LLM：OpenAI（兼容自定义 `base_url`）/ Claude / 通义千问
- 图像：Stable Diffusion WebUI（`SD_WEBUI_URL`）/ 通义万相
- 出图结果一律经 `common/storage.py` 落盘（本地或 S3），不再直连对象存储
- 提示词模板集中在 `PROMPT_TEMPLATES`（style / flat / model / fabric / sketch）
- 长耗时任务（生成、试衣）走 `common/taskqueue.py`，前端轮询状态；未配置 Key 时给出明确错误

## 工作流引擎

节点定义 JSON：`{name, label, handler_role[], auto_proceed, next[], reject_to}`；
实例支持认领（先到先得，按 `handler_role` 校验）、推进/驳回、`auto_proceed` 自动流转；内置模板见 `apps/workflow/definitions/`，单用户最多 10 条自定义流程。

## 安全

- API Key 双层 Fernet 加密（独立密钥 + 用户密码哈希），改密后旧 Key 失效。
- 角色 6 种：`admin` / `designer` / `pattern_maker` / `accountant` / `erp_sync`。
- 公网部署要点见 [运行与部署](运行与部署.md#3-公网访问)。
