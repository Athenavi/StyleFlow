# 运行与部署

> 目标：不需要懂数据库、虚拟环境或 Docker，一条命令跑起来；同一套东西支持本机、局域网、域名访问。

## 1. 一键运行

**前置**：Python 3.12+、Node.js 20+（<https://www.python.org/downloads/>、<https://nodejs.org/>；Windows 装 Python 时勾选 *Add python.exe to PATH*）。

```bash
# Windows：双击 start.bat，或
python start.py
# macOS / Linux
bash start.sh
```

首次启动自动完成：创建虚拟环境 → 安装后端依赖 → 生成 `.env` → 安装前端依赖 → 构建前端（3-10 分钟，之后秒启）→ 建库（SQLite）→ 创建管理员 → 启动前后端。停止：`Ctrl+C` 或 `python start.py --stop`。

启动后终端给出访问信息：

```
本机访问    http://127.0.0.1:3000
局域网访问  http://192.168.1.23:3000      ← 同一 WiFi 的手机可直接打开
接口文档    http://127.0.0.1:3000/api/v1/docs
管理后台    http://127.0.0.1:8000/admin/   ← Django 管理后台（走「后端端口」）
默认账号    admin / <随机密码，同时写入 data/管理员账号.txt>
```

| 参数 | 作用 |
|---|---|
| `--check` | 只做环境自检 |
| `--port 8080` / `--backend-port 9000` | 换端口（默认 3000 / 8000） |
| `--local` | 仅本机访问（默认监听 0.0.0.0，局域网可访问） |
| `--host 192.168.1.23` | 只绑定指定网卡 |
| `--dev` | 前端开发模式（不构建，改代码即时生效） |
| `--rebuild` | 强制重装依赖 + 重新构建前端 |
| `--db postgres` | 用 `.env` 里的 PostgreSQL 配置 |
| `--reset-admin` | 重置管理员密码并打印 |
| `--no-browser` / `--stop` | 不自动开浏览器 / 停止服务 |

**两个端口**：3000 是对外唯一的端口（页面 + API + 图片，全部同源，所以换 IP / 换域名都不用改配置）；8000 是后端，只有 Django 管理后台需要它（后台是尾斜杠路由，经前端代理会形成重定向循环）。

**数据**：全部在 `data/`（`styleflow.sqlite3`、`media/`、`static/`、`logs/`、`管理员账号.txt`）。备份 = 拷走 `data/` + `.env`。想清空重来直接删 `data/`。

## 2. 局域网访问

默认已监听 `0.0.0.0`，其他设备连同一 WiFi 打开「局域网访问」地址即可。打不开时：

```powershell
# Windows（管理员 PowerShell，放行一次；端口按实际改）
netsh advfirewall firewall add rule name="StyleFlow" dir=in action=allow protocol=TCP localport=3000
```
```bash
sudo ufw allow 3000/tcp     # Linux
```

排查：只本机能开 → 启动时用了 `--local` 或防火墙未放行；手机能开页面但图片不显示 → `.env` 的 `BACKEND_BASE_URL` 被填了绝对地址（必须留空）；路由器开了「AP 隔离」需关闭。

## 3. 公网访问

对外只需要转发到 `127.0.0.1:3000`；要 Django 后台再转发 `/admin/`、`/static/` 到 `127.0.0.1:8000`。
建议启动时加 `--local`（前后端只监听本机，由反向代理统一对外）。

### 3.1 Caddy（有域名 + 公网 IP，自动 HTTPS，推荐）

```bash
winget install CaddyServer.Caddy     # Windows；macOS: brew install caddy；Debian: apt install caddy
```
```caddy
# Caddyfile（放项目根目录，域名换成你自己的）
styleflow.example.com {
    encode gzip
    handle /admin/*  { reverse_proxy 127.0.0.1:8000 }
    handle /static/* { reverse_proxy 127.0.0.1:8000 }
    handle           { reverse_proxy 127.0.0.1:3000 }
    request_body { max_size 20MB }
}
```
```bash
python start.py --local      # 终端 1
caddy run --config Caddyfile # 终端 2
```

`.env` 同步修改：

```ini
CSRF_TRUSTED_ORIGINS=https://styleflow.example.com
SECURE_SSL_REDIRECT=true
SESSION_COOKIE_SECURE=true
CSRF_COOKIE_SECURE=true
```

### 3.2 Cloudflare Tunnel（无公网 IP）

```bash
cloudflared tunnel --url http://127.0.0.1:3000     # 打印 https://xxx.trycloudflare.com
```
正式用法：`cloudflared tunnel login/create/route dns styleflow styleflow.example.com`，然后 `cloudflared tunnel run --url http://127.0.0.1:3000 styleflow`。`.env` 配置同上。

### 3.3 Nginx 要点

`location /` → `proxy_pass http://127.0.0.1:3000`，另加 `/admin/`、`/static/` → `8000`；务必带上 `proxy_set_header Host / X-Forwarded-Proto`、`client_max_body_size 20m`、`proxy_read_timeout 300s`。

### 3.4 安全清单

- 改掉默认管理员密码（`--reset-admin` 或登录后修改），删除 `data/管理员账号.txt`
- 生产环境 `.env` 设 `DJANGO_DEBUG=false`，并通过 HTTPS 访问（打开上面三个 SECURE_* 开关）
- 设置 `CSRF_TRUSTED_ORIGINS` 为真实域名（必须带 `https://`）
- 不需要 Django 后台时，反代里不要转发 `/admin/`、`/static/`
- 定期备份 `data/`；多人使用建议切 PostgreSQL

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 端口被占用 | `python start.py --stop`，或换 `--port`；查占用：`netstat -ano | findstr :3000` |
| 提示未检测到 Python / Node | 装 3.12+ / 20+，重开命令行验证 `python -V`、`node -v` |
| 安装依赖或构建很慢 | 首次属正常；换镜像：`npm config set registry https://registry.npmmirror.com`、`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` |
| `npm ci` 失败 | 脚本会自动回退 `npm install`；手工兜底：`cd frontend && npm install` |
| 前端异常 | `python start.py --rebuild` |
| 后端启动即退出 | 看 `data/logs/backend.log`；多为 `DATABASE_MODE=postgres` 但 PG 未启动 |
| 忘了管理员密码 | `python start.py --reset-admin` |
| 新账号看不到菜单 | 角色由 `/admin/users` 或 Django 后台决定（`admin`/`designer`/`pattern_maker`/`accountant`/`erp_sync`） |
| 图片裂图 | `.env` 的 `BACKEND_BASE_URL` 必须留空（同源相对路径） |
| AI 生成无结果 | 需要自备 Key（`OPENAI_API_KEY`/`CLAUDE_API_KEY`/`TONGYI_API_KEY`）或本地 SD WebUI（`SD_WEBUI_URL`）；生成期间页面最长轮询 120 秒 |
| 虚拟试衣结果=原图 | 当前是模拟流程，接入 IDM-VTON 等真实模型后才会合成 |
| ERP 同步报未配置 | 在 `.env` 填 `ERP_DB_*` 后再同步 |
| 中文终端乱码 | `chcp 65001`，建议用 Windows Terminal |

## 5. 进阶切换（只改 `.env`，代码不用动）

```ini
# PostgreSQL（需另装数据库；脚本会自动补装 psycopg2-binary）
DATABASE_MODE=postgres
DB_NAME=styleflow ; DB_USER=styleflow ; DB_PASSWORD=... ; DB_HOST=localhost ; DB_PORT=5432

# Redis + Celery（多机/高并发；另开终端跑 worker）
TASK_BACKEND=celery
REDIS_URL=redis://localhost:6379/0
# worker: cd backend && celery -A config.celery_app worker -l info

# S3 / MinIO 对象存储
STORAGE_BACKEND=s3
MINIO_ENDPOINT=http://localhost:9000 ; MINIO_ACCESS_KEY=... ; MINIO_SECRET_KEY=... ; MINIO_BUCKET=styleflow
```

SQLite → PostgreSQL 迁数据：先 `python backend/manage.py dumpdata --indent 2 > backup.json`，切换后 `migrate` 再 `loaddata backup.json`。

## 6. 开发者：不上脚本手工跑

```bash
cd backend && python manage.py runserver 0.0.0.0:8000   # 或用本机 .venv 的解释器
cd frontend && npm run dev                              # 通过 frontend/.env.local 决定代理目标
```

配置参考见根目录 [.env.example](../.env.example)；架构与模块约定见 [设计摘要](设计摘要.md)。
